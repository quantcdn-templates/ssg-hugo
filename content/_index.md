# Welcome to Your Hugo Site

This is a minimal Hugo starter template configured for deployment to QuantCDN.

## Getting Started

Edit this file at `content/_index.md` to customize your homepage.

## Features

- ⚡ **Fast** - Hugo builds sites in milliseconds
- 🚀 **Automated Deployment** - Push to deploy with GitHub Actions
- 🌐 **Global CDN** - Powered by Quant's edge network
- 📱 **Responsive** - Mobile-friendly out of the box

## Next Steps

1. Add more content in the `content/` directory
2. Customize your templates in `layouts/`
3. Update site settings in `config.toml`
4. Push to GitHub to deploy automatically
